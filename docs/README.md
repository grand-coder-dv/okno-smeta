# ОкноСмета

Веб-приложение для расчёта стоимости пластиковых, алюминиевых и деревянных окон: графический редактор, спецификация и печатные формы.

{% hint style="info" %}
Код приложения лежит в папке `app/` в том же репозитории. Документация в `docs/` синхронизируется с GitBook через **Git Sync** и файл `gitbook-docs.yaml` в корне репозитория.
{% endhint %}

## Возможности

- графический редактор оконных конструкций;
- изменение размеров и схемы разбивки;
- перетаскивание импостов мышью или пальцем;
- точная установка импоста в миллиметрах от края рамы;
- выбор профиля, стеклопакета, фурнитуры и дополнительных работ;
- арочные и круглые конструкции;
- автоматический расчёт стоимости и подробная спецификация;
- счёт, договор, коммерческое предложение.
