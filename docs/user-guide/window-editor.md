# Редактор окна

## Что можно делать на холсте

| Действие | Как |
| --- | --- |
| Изменить габариты рамы | Потянуть за углы или задать размеры в инспекторе |
| Добавить вертикальный или горизонтальный импост | Кнопки в панели инструментов или перетаскивание |
| Точное положение импоста | Ввод расстояния в миллиметрах от края рамы |
| Несколько импостов сразу | Режим множественного выбора (см. `impost-selection.js`) |
| Арка или круг | Инструменты формы в редакторе |
| Отмена и повтор | Стандартные сочетания через историю правок |

## Смета и документы

После настройки изделия приложение пересчитывает стоимость (`estimate.js`) и формирует спецификацию. Из раздела отчётов можно вывести на печать счёт, договор, коммерческое предложение и спецификацию (`reports.js`).

{% hint style="success" %}
Технологические параметры (ширина рамы, створки, импоста) задаются отдельно для каждой системы в каталоге — см. настройки и `catalog.js`.
{% endhint %}
